# Authors and Contributors

The Digital Voice Modem Fixed Network Equipment Core Library is developed by
Bryan Biedenkapp (N2PLL) and the DVMProject community ("DVMProject Authors").

This file is based on the repository's Git history, supplemented by source
notices, recorded code origins, and earlier project credits. A name here does
not replace or alter the copyright notice or license in an individual file.
Contributor names and handles are consolidated where the history identifies
the same person.
